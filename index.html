Wiring Rules & Cautions
    ⚠ Safety first. Before touching wiring, remove all power.

    1Read the fault

    • Press Esc to acknowledge.
    • Open d007.
    • Look up the code.

    2Correct the cause

    • Fix cause for Type 2.
    • Type 1 re-trips until fixed.

    3Clear the fault

    • Press Stop.
    • Cycle power.
    • Set A450.
    • Cycle digital input.

    4Auto-restart

    • A451>0, A452>0.
    • A451>0, A452=0.
    • ⚠ Drive self-starts.
